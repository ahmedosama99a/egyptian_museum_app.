# Egyptian Museum Explorer - GitHub Pages

Static website with no Node.js, React, Python, backend, or AI requirements.

## Upload
Upload these files to the root of the GitHub repository:
- `index.html`
- `style.css`
- `app.js`
- `README.md`

Then open **Settings > Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, and save.
